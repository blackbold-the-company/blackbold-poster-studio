# 사진과 글자를 한 장으로 만들기

## 제작 지시를 쓰는 순서

대상과 비율 → 장면과 촬영 거리 → 제품과 제목이 만나는 위치 → 덩어리별로 정확한 글자와 줄바꿈 → 재질·빛 → 제한 순서로 기술한다. 초점은 한 군데만 둔다. 피사체와 글자가 겹칠 때는 받침과 제품을 알아보는 윤곽을 먼저 보호한다.

**선택 예시**  
입력은 ‘전남친피자 / 맵싸한 페퍼로니’, 선택은 ‘원형 피자 + 같은 폭의 브랜드 두 줄’이다. 크림색 세로면에 진홍 글자 ‘전남친’과 ‘피자’를 같은 너비로 쌓고, 탑뷰 피자를 두 줄 경계에 놓는다. 겹침은 글자 안쪽으로 한정한다. 원호를 따라 ‘사랑받고 자란 페퍼로니’와 ‘짠맛에 솔직한 소금’을 놓는다. 아래에는 ‘맵싸한 페퍼로니’ 한 줄. 텍스트 구획의 따옴표는 포스터에 인쇄하지 않는다.

## 결과를 만드는 두 경로

- **이미지 생성·편집** — 확정 문구만 따로 열거하고 어디에 몇 줄로 들어가는지 명시한다. 원본 수정이면 원본을 참조로 넘긴다. 서체를 말할 때는 획 끝, 속공간, 낱자 너비, 굵기의 대비를 묘사한다. 이미지 모델이 흉내 낸 서체는 ‘시각적 기준’으로만 설명한다.
- **실제 폰트로 조판** — 사용 가능한 원본 폰트와 한글 글리프를 확인한다. 사용자가 지정한 폰트가 없다면 접근 가능한 제작사 배포본 또는 사용자가 제공한 파일을 쓴다. 정확한 서체가 필수인데 확보하지 못하면 근사 시안임을 표시한다. 피사체·배경은 이미지 도구로 만들고 허용된 조판 도구에서 벡터 텍스트를 얹는다. 원형 글자는 경로를 따라 조판한다. 최종 렌더링에서 대체 폰트, 글자 잘림과 행폭을 확인한다.

## 마지막으로 읽을 것

원문과 완성본을 단어 단위로 맞춘다. 제목만 읽었을 때 상품을 알 수 있는가? 작게 봐도 서브 카피가 한 덩어리로 보이는가? 제품의 기름 윤기, 빵결, 유리 반사 같은 단서가 남았는가? 사진의 복잡한 패턴에 글자가 걸리면 외곽선을 씌우기 전에 단순한 여백으로 옮긴다. 허구의 가격·원산지, 생성기가 추가한 가짜 로고·영문·마침표를 제거한다.
