눈누 미리보기에 실제 문구를 넣어 복잡한 받침, 숫자, 외래어 폭을 비교한다. 얇은 획이 사진에 먹히면 같은 글꼴의 굵기를 올리거나 자리를 옮긴다. 해당 굵기가 없으면 다른 가족을 선택한다. 링크에서 제작사와 이용 조건을 확인한다.

## 서브 카피에 밀도를 주는 법

- 한 덩어리에 한 메시지. “겉은 바삭 속은 버터”라면 왼쪽에 작은 ‘겉은 / 속은’을 맞추고 오른쪽에 굵은 ‘바삭 / 버터’를 같은 기준선 두 개에 놓는다. 단어 사이의 거리로 무엇이 짝인지 알 수 있게 한다.
- 같은 그룹의 두 행은 가깝게, 다음 그룹은 더 멀리. 모바일 1080px 폭 시안의 출발값은 강조 60–90px, 세부 32–44px. 실제 글자의 보이는 높이로 조정하고 360px 폭에서도 읽어본다.
- 연관어를 한 줄에 둔다. ‘맵싸한 / 페퍼로니’보다 ‘맵싸한 페퍼로니’가 한 단위라면 통째로 움직인다. 조사가 줄 맨 앞에 홀로 남지 않게 한다.
- 원형에서는 바깥 글자와 피자 테두리 사이를 한결같이 띄운다. 짧은 구절 두 개로 나눠 아래쪽도 똑바로 읽히게 한다. 자간을 한없이 벌려 원을 채우지 않는다.
- 위 ‘전남친’과 아래 ‘피자’의 보이는 잉크 양끝을 맞춘다. 아래 줄만 가로로 늘리고 실제 줄폭과 획의 눌림을 확인한다. 메인 장평과 서브 장평은 따로 취급한다.
- 마침표를 없앤 자리에는 줄바꿈이나 여백을 쓴다. 띠와 배지를 더 붙여 빈 곳을 메우지 않는다.
