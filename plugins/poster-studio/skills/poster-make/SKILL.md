# 선택한 포스터 만들기

1. 직전 추천 목록에서 번호를 찾아 제품, 헤드라인, 장면을 가져온다. “3번 이미지와 1번 문구”는 각각 그 번호에서 가져온다. 번호가 가리키는 목록이 대화에 없을 때만 제목이나 목록을 요청한다. 단일 콘셉트로 직접 제작해 달라는 요청은 바로 시작한다.
2. 수정이면 원본을 확인하고 변경 범위를 적는다. “메인은 두고 서브만”이면 메인 글꼴·위치·제품 사진·색은 잠근다. 변경할 작은 문구와 줄바꿈을 먼저 확정하고 기존 이미지 참조를 사용한다. 원본이 여러 장이면 지정된 장수와 순서를 보존한다.
3. [한글 조판과 서체](references/type.md)에서 한 조합을 골라 주역과 보조 역할을 정한다. 브랜드 지정 폰트를 우선한다. 읽기 순서는 브랜드/상품 → 한 줄의 훅 → 필요할 때만 재료나 행사 정보다. 같은 말 두 번, 의미 없는 일련번호·영문·배지를 걷어낸다.
4. [제작·교정](references/production.md)에 따라 비율, 제품 크롭, 기준선, 사용 색, 확정 문구와 줄바꿈을 잡는다. 별도 요청이 없으면 모바일 피드 4:5 한 장. 시리즈면 공통 규칙 하나를 유지하고 각 장의 구도와 카피는 제품별로 바꾼다. 포스터에 들어갈 문장 끝의 마침표는 모두 제거한다. 고유 표기나 의미 있는 물음표는 원문에 맞춘다.
5. 현재 환경에서 실제로 쓸 수 있는 이미지 생성·편집 도구를 호출해 이미지를 제작한다. 선택이 끝난 사람에게 프롬프트나 중간 기획안만 돌려주지 않는다. 특정 폰트 파일을 지정했거나 긴 한글이 필수면 글자 없는 이미지와 실제 폰트 조판 경로를 우선한다. 도구의 출력 경로와 이용 가능한 조판 기능을 먼저 확인한다.
6. 완성 이미지를 검토할 수 있으면 실제로 열어 원문 맞춤법·줄바꿈·가림·마침표를 확인한다. 문제 영역을 고쳐 다시 읽고 최종 이미지를 제공한다. 도구가 결과를 화면에 직접 표시했고 확인 기능이 없으면 검수했다고 말하지 않는다. 이미지 생성 기능이 없는 환경에서만 재현용 지시문과 복사용 확정 문구를 제공하고, 실제 이미지가 만들어지지 않았음을 명시한다.
