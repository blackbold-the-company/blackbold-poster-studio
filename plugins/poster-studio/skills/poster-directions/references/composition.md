# 같은 제품으로 다른 그림 만들기

처음 다섯 초 안에 보일 제품의 모양과 동작을 한 가지씩 적는다. 아래는 그 답으로 구도를 바꾸는 예시다. 한 장에 전부 적용하지 않는다.

| 관찰한 단서 | 종이 위에 놓는 법 | 글자와 사진이 만나는 곳 |
| --- | --- | --- |
| 피자는 둥글다 | 탑뷰 한 판을 정중앙에 놓고 제목 두 줄을 뒤에 깐다 | 테두리와 나란히 재료 이야기가 돌아간다 |
| 김이 솟는다 | 그릇을 아래로 내리고 역광으로 증기를 보인다 | 검은 여백 속 작은 문장이 위로 느슨해진다 |
| 버거는 손으로 쥔다 | 쥔 손을 크게 크롭하고 엄지와 패티를 함께 살린다 | 두 줄 낱말의 한 획만 손 뒤로 보낸다 |
| 빵은 쪼개진다 | 두 반쪽과 속결이 보이는 틈을 만든다 | 틈을 사이에 두고 두 단어가 답한다 |
| 소다는 터진다 | 병을 화면 귀퉁이로 기울이고 위쪽을 크게 비운다 | 짧은 음절이 큰 기포와 한두 번만 겹친다 |
| 딸기우유는 층이 섞인다 | 접사로 연분홍 경계선을 가로로 잡는다 | 짙은 문장을 우유 쪽에 걸쳐 놓는다 |
| 만두는 속이 숨는다 | 한 알의 단면을 신문 1면 사진처럼 과감히 자른다 | 큰 속보 한 줄 아래 작은 사실 한 줄을 맞춘다 |
| 떡은 길게 딸려 온다 | 젓가락을 화면 밖으로 빼고 당겨진 대각선을 쓴다 | 질문과 대답의 기준선을 엇갈리게 둔다 |
| 밴드가 지하에서 연주한다 | 계단 아래 빛과 뒷모습을 멀리 잡는다 | 계단 폭에 맞춰 행이 짧아진다 |
| 천은 접힌다 | 주름을 비스듬히 훑는 빛으로 재질을 보여준다 | 평평한 면에만 정갈한 활자를 얹는다 |

## 일곱 안을 나란히 읽기

썸네일을 흑백으로 만든다고 생각한다. 검은 덩어리의 크기와 위치만으로 둘을 구별할 수 있는가? 카피를 서로 교환해도 멀쩡하면 제품 관찰이 약하다. 사진 없이도 흥미로운 한 줄, 글자 없이도 제품이 잡히는 한 컷을 먼저 만든 뒤 둘 사이의 접점을 고른다.
