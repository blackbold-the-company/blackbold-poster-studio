# 포스터 방향 고르기

입력 예시는 “전남친피자 / 맵싸한 페퍼로니 / 다시 생각나는 맛”이다. 제품명 하나만으로도 시작한다. 첨부한 시안이 있으면 먼저 보고, 고정 브랜드명·표기·문구·비율과 바꿀 수 있는 요소를 구분한다. 기존 포스터 수정이나 앞서 제시한 번호 선택이면 일곱 안을 다시 뽑지 말고 같은 플러그인의 poster-make 지침으로 이어간다.

1. 전달할 사실과 연상어를 나눈다. “햇살을 한껏 받은 밀가루” 같은 의인화는 가능하다. 원산지·가격·행사 일시·재료 함량은 제공받은 범위에서만 쓴다. 고유명사의 오탈자로 보이는 표기도 사용자가 지정했으면 유지한다.
2. 단서가 한 제품에 모이면 같은 제품의 일곱 해석을 만든다. 서로 다른 아이템을 추천해 달라는 입력이면 준 후보에서 일곱 개를 고른다. 후보가 모자라면 같은 아이템의 다른 연출임을 표시한다. 카테고리를 마음대로 바꾸지 않는다.
3. 자세한 비교 기준과 장면의 출발점은 [구도 노트](references/composition.md)를 읽는다. 각 안에 제품에서 관찰할 수 있는 단서(원형, 단면, 기포, 주름, 사용 동작 등)를 하나 넣는다. 형태·관찰 거리·문자 위치 중 두 가지 이상이 다른 안을 고른다. 같은 중앙 누끼에 배색만 바꾼 안은 합친다.
4. 입으로 읽어 짧은 카피를 만든다. 브랜드 어감, 맛의 반전, 소리, 대화, 쓰는 동작에서 가져온다. 같은 라임을 일곱 번 반복하지 않는다. 한글 카피의 종결 마침표를 뺀다. 영문은 지정된 이름이나 언어유희가 성립할 때만 쓴다.
5. 정확히 일곱 줄을 1–7의 고정 번호로 제시한다. 각 줄은 **실제로 찍힐 헤드라인**과 **제품이 어디에 어떻게 보이고 어떤 글자가 곁에 붙는지** 한 문장으로 쓴다. 가장 잘 맞는 한 안에만 ‘추천’을 붙이고 단서와 연결되는 이유를 한 줄로 준다. 표 밖에 여덟 번째 안을 추가하지 않는다.
6. “번호 하나를 고르세요”로 마친다. 이 단계에서는 이미지를 생성하지 않는다. 다음 턴에서 번호·제목·“2번 구도에 5번 카피”를 이 목록에 그대로 대응시킨다. “셋 중 아무거나 바로 만들어”처럼 선택을 위임하면 의도를 충족하는 한 안을 골라 같은 답에서 제작을 계속한다.
