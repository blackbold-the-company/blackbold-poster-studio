# 블랙볼드 포스터 스튜디오

**아이디어 몇 마디를 던지고, 일곱 개 중 한 번호를 고르면, 한글 포스터 한 장이 나옵니다**

> **나**　전남친피자 / 맵싸한 페퍼로니 / 헤어졌는데 자꾸 생각나는 맛  
> **스튜디오**　같은 피자를 찍는 서로 다른 방법 일곱 가지를 보여줘요  
> **나**　1번으로 가자　‘전남친’이랑 ‘피자’ 양끝 맞춰줘

## 첫 포스터 만들기

1. 플러그인을 켜고 **제품이나 행사 + 떠오르는 말 두세 개**를 적습니다
2. 카피와 장면이 짝지어진 일곱 안에서 번호를 고릅니다　**“2번 구도에 5번 카피”**처럼 섞어도 됩니다
3. 이미지 생성이 가능한 대화에서 완성된 포스터를 받습니다　**“메인은 두고 서브만 두 줄로, 마침표는 빼줘”**라고 이어서 수정할 수 있습니다

바로 써 보세요

```text
소금빵 / 겉바속촉은 너무 흔해 / 버터가 본심인 빵
```

```text
동네 독립서점의 금요일 낭독회 / 비 오는 밤 / 책 읽는 손
```

## 한 제품에서 일곱 장면이 어떻게 나오나요?

**전남친피자** 기획 대화의 예시입니다. 번호마다 포스터에 실제로 들어갈 말과 촬영 장면을 함께 봅니다

| 번호 | 포스터에 찍힐 말 | 화면에 보일 장면 |
| --- | --- | --- |
| **1 추천** | **전남친 / 피자** | 같은 폭의 두 줄 사이에 둥근 피자 한 판, 테두리를 도는 재료들의 자기소개 |
| 2 | 쭉 끌리네 | 한 조각을 들어 올린 손과 비스듬히 늘어진 치즈, 그 사이를 건너는 가는 명조 |
| 3 | 자니? / 한 판 남았어 | 어두운 식탁 위 열린 상자를 멀리 찍고, 두 문장을 좌우 끝에 엇갈려 배치 |
| 4 | 맵다며 / 또 왔네 | 화면 가득 찬 페퍼로니 한 장의 기름진 접사, 두 줄 대꾸를 왼쪽 아래에 밀착 |
| 5 | 반반은 못 해 | 한쪽은 빈 종이, 한쪽은 반 판의 피자, 단면과 문장의 오른쪽 끝을 맞춘 수직 구도 |
| 6 | 번호는 지웠는데 | 접힌 주문 메모가 제목을 품고, 뒤쪽으로 상자의 붉은 모서리가 살짝 들어오는 정물 |
| 7 | 식기 전에 와 | 오븐에서 막 꺼낸 팬을 옆에서 찍고, 짙은 여백으로 올라가는 김 사이에 좁은 세로 제목 |

1번을 추천하는 이유는 **‘전남친’이라는 이름과 피자의 동그란 형태를 한눈에 읽을 수 있기 때문**입니다. 원호에는 ‘사랑받고 자란 페퍼로니’와 ‘짠맛에 솔직한 소금’을 나눠 놓습니다. 실제 추천은 입력에 맞춰 매번 달라집니다

## 실제 선택으로 만든 포스터

“비 오는 금요일, 독립서점 낭독회, 책 읽는 손”을 입력하고 **2번의 장면에 1번의 카피**를 골랐습니다. 한 사람의 손이 물러나고 다음 사람의 손이 한 줄을 짚는 구도에 ‘빗소리 사이로, 한 줄씩’을 얹은 결과입니다

## 설치

### ChatGPT 워크스페이스

GitHub 플러그인 가져오기를 지원하는 워크스페이스에서 관리자가 한 번 등록합니다

1. **Admin → Plugins → Add → Import marketplace**를 엽니다
2. **Source**에 이 저장소의 GitHub URL을 입력하고 **Path**는 비웁니다　브랜치는 기본 브랜치인 **main**을 선택합니다
3. 가져오기가 끝나면 구성원이 사용할 수 있게 설치 정책을 **Available**로 설정합니다
4. 구성원은 **Plugins**에서 **블랙볼드 포스터 스튜디오**를 찾아 설치하고 새 대화에서 위 예시 중 하나를 입력합니다

이미지 생성이 활성화된 대화를 사용하세요. 이미지 기능이 없는 환경에서는 조판 지시와 확정 카피까지 받을 수 있습니다. [ChatGPT 관리자용 공식 가이드](https://learn.chatgpt.com/docs/enterprise/plugin-management)

### Codex

플러그인을 지원하는 Codex에서 저장소를 복제한 뒤 해당 폴더에서 실행합니다

```sh
codex plugin marketplace add .
codex plugin add poster-studio@blackbold-design
```

새 세션을 열어 **블랙볼드 포스터 스튜디오**를 선택하고 아이디어를 입력합니다. 별도 API 키나 폰트 파일을 이 저장소에 넣을 필요는 없습니다. [OpenAI 플러그인 패키징 가이드](https://developers.openai.com/plugins/build/plugins)
